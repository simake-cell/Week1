# Introduction
The project is an interactive digital pet, called a starbie, that can jump, eat, sleep, and operate almost autonomously. 
It started with a care package containing the necessary symbol, footprint, and controller by Logan Peterson in KiCad. 

## The process
The schematics used a XIAO-ESP32, two push switches, a sensor, a digital display, a resistor, and a connector.

I avoided overlapping wires to create a clean working circuit. 
After assembling the components, I tried to fix as many warnings as possible and drew some pixel art to add to my board. 
I assigned footprints to each part and went into PCB editor mode.
